# Портфолио Арнура

Адаптивное портфолио на React и Vite. Сайт и API можно опубликовать на Cloudflare Pages, а сообщения формы сохранять в Cloudflare D1. Для отправки писем форма использует внешний сервис FormSubmit.

## Настройка сайта

1. В `src/App.jsx` измените имя, описание и навыки, если нужно.
2. В `shared/projects.js` укажите свои проекты и адреса `demoUrl` / `sourceUrl`.
3. Проверьте адрес электронной почты в контактном блоке.

В разделе портфолио показаны три учебных дизайн-концепта с оригинальными SVG-превью. Это не заказы реальных клиентов; так проекты не вводят потенциальных заказчиков в заблуждение. Тексты, описание и изображения карточек находятся в `shared/projects.js` и `public/projects/`.

## Локальный запуск

Нужен Node.js версии 22.13 или новее.

```bash
npm install
npm run dev
```

Сайт работает на `http://localhost:5173`, Express API — на `http://localhost:3000`. Локальный backend сохраняет сообщения в SQLite-файл `server/data/portfolio.sqlite`. В опубликованной версии API работает через Cloudflare Pages Functions, а база D1 используется для резервной копии. Письмо отправляется через FormSubmit на `arnurmedetuly777@gmail.com`.

### Активация отправки писем

При первом тесте FormSubmit попросит подтвердить адрес `arnurmedetuly777@gmail.com`. Откройте почту, найдите письмо от FormSubmit (в том числе в папке «Спам») и нажмите ссылку подтверждения. Пока адрес не подтверждён, доставка не настроена. Это подтверждение делается один раз; пароль Gmail сайту не нужен.

После подтверждения отправьте тест через форму и проверьте входящие и папку «Спам». Форма показывает успех, если FormSubmit подтвердил приём запроса; сам почтовый сервис может доставить письмо не мгновенно или поместить его в спам. Копия сообщения дополнительно сохраняется в D1/SQLite. Если база недоступна, это не отменяет уже принятую FormSubmit отправку.

## Бесплатная публикация через Cloudflare

Нужны аккаунты Cloudflare и GitHub. Если хотите использовать только бесплатные возможности, перед подключением проверьте актуальные условия тарифов Cloudflare.

1. В Cloudflare откройте **Workers & Pages** и создайте базу **D1 SQL database** с именем `arnur-portfolio-db`.
2. В меню базы откройте **Console** и выполните SQL из файла [`migrations/0001_create_contact_messages.sql`](./migrations/0001_create_contact_messages.sql). Это создаст таблицу для формы.
3. Откройте **Workers & Pages → Create application → Pages → Connect to Git**. Разрешите Cloudflare доступ к GitHub и выберите `PUMBA24/arnur-portfolio`.
4. В настройках сборки укажите production branch (ветку, в которую публикуете код), build command `npm run build` и build output directory `dist`. Корневую директорию оставьте пустой и создайте проект.
5. После первой успешной сборки в проекте Cloudflare Pages откройте **Settings → Bindings → Add → D1 database**. Укажите variable name `DB`, выберите `arnur-portfolio-db`, сохраните изменения и запустите **Redeploy**.

Для проекта используйте имя `arnurmedetuly777-portfolio`, если Cloudflare его принимает. Бесплатный адрес будет `https://arnurmedetuly777-portfolio.pages.dev`; покупать отдельный домен не нужно. Если это имя занято, выберите свободное и замените домен в `index.html`, `public/robots.txt`, `public/sitemap.xml` и этом README.

После успешной сборки проверьте `https://<адрес-сайта>/api/health`: ответ `{"status":"ok"}` означает, что API доступен, но сам по себе не проверяет подключение к D1 или доставку почты. Затем проверьте отправку формы по инструкции выше. Чтобы опубликовать новые изменения, сначала сохраните их в Git и отправьте (`push`) в подключённую production-ветку; Cloudflare запустит новую сборку автоматически.

### Как попасть в поисковую выдачу

Файлы `robots.txt` и `sitemap.xml` уже подготовлены. После публикации добавьте адрес сайта в [Google Search Console](https://search.google.com/search-console) и [Яндекс Вебмастер](https://webmaster.yandex.ru/), подтвердите сайт по инструкции сервиса и отправьте sitemap: `https://arnurmedetuly777-portfolio.pages.dev/sitemap.xml`. Индексация может занять от нескольких дней до нескольких недель; появление сайта и его позиция по запросам не гарантируются.

### Лимиты сервиса

Лимиты и условия Cloudflare и FormSubmit могут меняться. Перед использованием проверьте актуальные условия на сайтах этих сервисов.

Проверить доступность API можно по `/api/health`.
