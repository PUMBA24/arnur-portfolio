# Портфолио Арнура

Адаптивный сайт-портфолио на React и Vite. Express-backend предоставляет проекты и принимает сообщения из формы обратной связи, сохраняя их в SQLite.

## Перед публикацией

Обновите личную информацию под себя:

1. В `src/App.jsx` измените имя, описание и навыки, если нужно.
2. В `server/index.js` отредактируйте список проектов, описание и технологии; добавьте ссылки `demoUrl` на работающие демо и `sourceUrl` на исходный код.
3. Замените учебные проекты собственными работами, прежде чем отправлять портфолио работодателям.
4. Обновите описание сайта и имя в `index.html`.

Карточки проектов в исходной версии — только примеры оформления: укажите в портфолио реальные работы.

## Локальный запуск

Нужен Node.js версии 22.13 или новее.

```bash
npm install
npm run dev
```

Vite показывает сайт по адресу `http://localhost:5173`, backend работает на `http://localhost:3000`. Команда `npm run dev` запускает оба сервера. Для создания production-сборки выполните `npm run build`; `npm start` запускает сервер, который раздаёт собранный сайт и API.

### API

- `GET /api/health` — проверить состояние сервера.
- `GET /api/projects` — получить список проектов.
- `POST /api/contact` — принять JSON с полями `name`, `email` и `message`.

Сообщения формы сохраняются на сервере в `server/data/portfolio.sqlite`. Чтобы получить их, используйте локальный файл базы данных или консоль хостинга с доступом к диску. Форма не отправляет электронные письма и не уведомляет о новом сообщении: настройте отдельный сервис отправки почты, если нужны уведомления.

## Публикация на GitHub и Render

1. Создайте публичный репозиторий на GitHub. Не загружайте в него `node_modules`, папку `dist` или базу с сообщениями.
2. Из папки проекта отправьте исходный код в новый репозиторий, заменив `ВАШ_АККАУНТ` и `ВАШ_РЕПОЗИТОРИЙ` своими данными:

   ```bash
   git init
   git add .
   git commit -m "Create portfolio website" -m "Co-authored-by: Copilot <223556219+Copilot@users.noreply.github.com>"
   git branch -M main
   git remote add origin https://github.com/ВАШ_АККАУНТ/ВАШ_РЕПОЗИТОРИЙ.git
   git push -u origin main
   ```

3. В Render войдите через GitHub, выберите **New → Blueprint**, подключите репозиторий и примените настройки из [`render.yaml`](./render.yaml). Конфигурация собирает сайт, запускает Node.js API, проверяет `/api/health` и сохраняет сообщения формы на постоянный диск. Для этого сервиса нужен план Render с поддержкой persistent disk; условия и стоимость хостинга смотрите в аккаунте Render.

После успешного развёртывания Render покажет публичный адрес сайта вида `https://arnur-portfolio.onrender.com`. Проверьте форму на размещённом сайте: сообщения появятся в SQLite на постоянном диске, но письмо-уведомление отправляться не будет.

**GitHub Pages не запускает Node.js backend.** Он подходит только для статической версии сайта; форма не будет работать без размещённого API. Для сайта с работающей формой используйте Render Blueprint выше.
